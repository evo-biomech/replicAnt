# Epic MegaGrants Program — Notes

> For a detailed analysis of funded projects, presentation strategies, fiscal dynamics, and replicAnt's suitability, see [megagrants_strategic_analysis.md](megagrants_strategic_analysis.md).

## Program Overview
Epic MegaGrants is a $100 million initiative (evolved from the $5M Unreal Dev Grants, 2015) that funds projects using or advancing Unreal Engine, open-source tools, and creative/scientific applications built on Epic's ecosystem. Operates on a "rising tide lifts all boats" philosophy.[1][4]

## What They Fund
- Projects using Unreal Engine in innovative ways
- Open-source tools that benefit the UE community
- Applications across games, film, architecture, education, **scientific research**, and more
- Both new projects and extensions of existing work
- Key categories: "Tools and Open-Source Development" and "Education"[2][5]

## Funding Range
- $5,000 to $500,000; most grants in the **$5,000–$50,000** range[1][16]
- **$30,000 threshold** is a pivot point for review intensity[16]
- Requests above $50,000 face additional scrutiny, milestones, and potential phased funding[12][16]

## What Makes a Strong Application
1. **Clear use of Unreal Engine** as core technology (not peripheral)
2. **Open-source commitment** — freely available tools benefit the broader community
3. **Demonstrated progress** — working prototypes, publications, community traction
4. **Clear roadmap** — specific goals for what the grant will enable
5. **Impact potential** — how many people/fields will benefit
6. **Team credibility** — track record of delivering on similar projects
7. **High-quality video pitch** — 2–5 minute video is the primary review tool[15]
8. **Community validation** — GitHub activity, Discord, social proof[17][18]
9. **"Giving back" framing** — position as partner in Epic's ecosystem mission[14][16]

## Our Strengths for This Application
- **UE is central**: replicAnt is literally built on Unreal Engine — it's the rendering backbone
- **Open-source**: All tools (replicAnt, SMILify, OmniTrax, scAnt) are MIT-licensed
- **Published science**: *Nature Communications* paper explicitly crediting UE
- **Active development**: Major UE 5.4 migration just completed (March 2026)
- **Ecosystem**: Not a single tool but an interconnected suite of open-source projects
- **Novel domain**: Bringing UE to biological research — underserved but high-impact community
- **Community traction**: Combined 350+ GitHub stars, 58+ forks, multiple peer-reviewed publications

## Application Tips (from strategic analysis)
- Lead with the Unreal Engine angle — they want to see UE being used in exciting ways
- **Produce a polished 2–5 min video pitch** — this is the single most important element[6][15]
- Emphasise open-source nature and community benefit
- Be specific about what the funding will enable (not vague aspirations)
- Include visuals — rendered outputs, pipeline diagrams
- Show existing community/academic validation before applying[17][19]
- Budget transparency: show exactly how funds translate to deliverables[13]
- Post-submission: send meaningful updates once or twice a month[18]
- Mention any previous Epic/UE community engagement (including prior scAnt grant)
